Robust Height Planning

Overview

During additive manufacturing, small height errors can accumulate as each layer is added. Measuring the part can interrupt the build. This project asks whether the required heights can be guaranteed with zero inspection and, when a measurement is needed, which layer is suitable.

The first diagram shows the limits after each layer and the tolerance at the end of the repair. The planner takes these limits, the estimated starting height, and bounds on process and measurement errors. The planner diagram shows how these inputs become an inspection plan and height increments for the deposition controller.

How the planner works

Before deposition, the planner first tests whether a single sequence of commanded layer increments can keep the height inside its limits for every allowed error. The model includes uncertainty in the heights, deposition model, and layer-to-layer disturbances.

If an inspection is needed, the planner tests candidate layers and amounts to deposit before inspection. It considers each range of possible sensor readings, including measurement error. Linear programming computes safe bounds for the remaining cumulative height increments. A backward check from the final layer confirms that these bounds can be reached using allowable layer increments. A plan is certified only if a safe completion exists for every reading range.

During deposition, the actual reading selects the corresponding continuation. The planner can give the lower-level controller a range of safe increments for the next layer, leaving it room to meet other process objectives.

Results for a case study groove repair

The numerical case study used an Inconel 625 groove and a final target height of 0.83 mm relative to the surrounding surface, with a tolerance of ±0.25 mm. The fixed setting commands the midpoint of the feasible range for the total height increment before inspection. The planner found the following options under the study’s uncertainty bounds.

Planning choice Certified result
Zero inspections No feasible sequence
One inspection with a fixed pre-inspection setting Five candidates, layers 11–15
One inspection with a flexible pre-inspection setting Eight candidates, layers 10–17

The case study plots show an example that inspects after layer 14, leaving seven layers for correction. The left panel shows where inspection is feasible. The middle panel shows the allowable increments and the commands chosen for the median inspection reading. The right panel shows that the worst-case height band stays within the layerwise and final limits for the illustrated plan. It also shows the spread of 3,000 simulations.

The Python implementation computed a single inspection plan in about 0.8 seconds on the study processor. The window of certified layers gives a scheduler options when an inspection device or operator is shared across builds.
